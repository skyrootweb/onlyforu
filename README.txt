SURPRISE WEBSITE - kaise use karein

1. Photos badalne ke liye: images folder me photo1.jpg ... photo5.jpg ko
   apni photos se replace karo (same naam rakhna).
2. Naam badalne ke liye: script.js ke top par NAME = "Beautiful" edit karo.
3. Text badalne ke liye: index.html kholo aur text edit karo (Notepad / VS Code).
4. Dekhne ke liye: index.html par double-click karo.
5. Link share karne ke liye: netlify.com/drop par poora folder drag-drop kar do.
6. Gaana: apni Inna Sona ki mp3 file ka naam song.mp3 rakh kar music folder me daal do. Pehle tap par bajna shuru hoga.
